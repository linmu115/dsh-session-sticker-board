# 关联笔记快捷解除入口

在会话输入框上方展开关联笔记后，与“在 Obsidian 打开”“引用到本轮”并列提供“解除关联”按钮。按钮使用断链图标、DSH 主题错误色、键盘焦点样式，并支持窄屏换行。操作期间禁用重复点击。

实际页面验收发现原关联栏铺满整个会话区域，使左侧笔记按钮落入 DSH 宽度拖拽条的点击区域。关联栏现在沿用 DSH 的 `--dsh-chat-content-width` 并居中，与会话内容栏对齐，保留两侧拖拽操作区域。

解除仅作用于选中的笔记／会话关系，不删除 Obsidian 笔记正文，也不删除已经加入本轮的引用。调用 Companion 的现有 link-delete，保存可恢复的解除意图并触发共享定位标记清理，再按版本更新 Maintenance 关系。若后台同步已完成同一删除，直接视为成功；短暂版本竞争重新读取后核对。断线等失败保留按钮及关联并显示错误。请求发起前核对当前会话归属，旧轮询结果不能在解除完成后把关联重新显示出来。

验证：类型检查、构建及全部 16 个测试文件、110 项测试通过；关联笔记的 8 项测试覆盖打开、引用、解除、Companion 失败、后台同步竞争及错误会话隔离。不调用模型，不删除真实关联作为测试。

安装为 0.7.3-rc2.13 的独立本地构建，保留已安装 Annotation Core 发送冲突修复及 Companion 标记清理修复。产物位于 artifacts/unlink-note-button-20260914，按包哈希核对副本安装。
