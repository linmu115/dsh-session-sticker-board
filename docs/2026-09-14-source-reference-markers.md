# 来源会话的蓝色引用入口

对应 Maintenance 规格修订 `e458ce4` 的 ST10–ST15、AC28。本变更只实现会话贴纸客户端；目标 Y 的主干图及 X → Y 关系由 Annotation / Maintenance 维护。

## 用户行为

- 在来源 X 的完整助手回复中选文后，新建或选择目标会话 Y。继续保留先选工作区、在创建前核对所选完成回复、失败重试复用操作身份的流程。
- 绑定引用后，贴纸只保存真实消息 ID、最多 4,000 字的选文及重复位置。保存成功进入 Y 的真实会话；不自动发送，不复制完整来源历史。
- 再次打开 X 时，按服务器保存的活动关系恢复选文高亮与蓝色箭头符号。普通贴纸仍使用原来的红色符号；同一选文已存在普通贴纸时复用其高亮颜色。
- 同一位置只有一个目标时，点击蓝色符号进入该真实会话；有多个目标时先显示目标列表。同一目标的多条独立引用只显示一个跳转选项。
- 解除一条关系后，只移除该关系对应的活动入口。其余目标仍可进入，共享选文仍有高亮，普通贴纸与源正文不受影响。

## 接口与恢复

使用共享合同 `GraphSourceMarkerPage`，调用当前实例的 `POST /maintenance-knowledge/api/source-markers`，输入 `{ nativeSessionId, after? }`。后端返回按源查询、已经核对权威引用状态的分页短选区；客户端不保存第二份关系真源。

贴纸来源新增 `source.locator = { messageId, selectedText, occurrence }`。真实消息身份由完成回复的 `finalNode.messageId` 获取，渲染时反向查找当前页面的展示节点，不把展示编号保存为消息身份。

打开来源、窗口恢复焦点、重新可见，以及 `dsh-session-references-changed` 事件都会刷新标记；可见页面另每 15 秒刷新。点击符号或选择目标时再次向服务器查询，已解除或无法核对的关系不跳转。离开来源后，尚未完成的异步目标解析不会突然切换会话。
