# 0.4.4 - DSH alpha.1 composite anchors

- Deep links now recognize DSH 0.1.2-alpha.1 conversation DOM keys that prefix the durable message ID with native context metadata.
- Exact legacy anchor keys remain supported.
- Obsidian references can now locate the rendered message, open the Annotation Core dialog, and acknowledge the pending Bridge action.
- The build-time Annotation Core source follows the maintained compatibility branch instead of pinning one commit; runtime integration remains capability-driven with an open peer range.
