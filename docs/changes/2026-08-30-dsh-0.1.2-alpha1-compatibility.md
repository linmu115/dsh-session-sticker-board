# 0.4.20 — DSH 0.1.2-alpha.1 compatibility record

## Upstream breaking changes

- `dsh-client-runtime` was removed.
- Session snapshots no longer contain authoritative Chat `order` and `nodes`; those values live in the `uiConversation` Chat target.
- Rendered node keys may combine native context metadata with the durable message ID.
- The Session catalog is asynchronous during startup, and the Web UI selection toolbar no longer has the former fixed DOM ownership.

## Sticker Board changes

- Inject the native Session Controller and Chat UI services without creating npm installation constraints.
- Resolve stickers by durable Chat node ID and map them to the current rendered key, including alpha.1 composite anchors.
- Read Chat `order` and `nodes` from `uiConversation.binding(sessionId).target("chat")` for restore, pagination, and deep links.
- Wait for the Session catalog to leave `pending` before accepting or rejecting an Obsidian navigation action.
- Discover the shared selection toolbar in the Obsidian Web Viewer and mount one functional Sticker action there.
- Rebuild multiline selections through a DOM character map so Markdown spanning lists or inline nodes remains highlightable.
- Keep Obsidian navigation one-shot and surface-scoped; manage backlink deletion through Bridge capabilities.

No RC2 compatibility shim is retained.
