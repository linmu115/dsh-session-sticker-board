# Bound optional projection lookup before ordinary sticker editing

Diagnosis: beginCreate awaits createMessageAnchor (local SHA-256) and resolveLogicalLocation before setEditor. The production resolver calls resolveMaintenanceProjection, whose fetch previously had no default timeout. A stalled /dsh-session-maintenance/api reference:resolve request could therefore leave the Core selection action pending indefinitely. Initial workspace.ensure uses /maintenance-knowledge/api/legacy-state with a separate 15-second deadline; its session-note warning does not prove that reference:resolve failed or identify the live cause.

Fix: bound reference:resolve to 15 seconds with AbortSignal.timeout and combine an explicit caller signal using AbortSignal.any. Existing caller behavior already treats failed identity enrichment as optional and retains native/legacy identity; this change neither bypasses save ownership nor adds storage, retries, or writes. Successful logical identity remains preserved. Saving remains subject to the existing authoritative store and migration checks.

Validation: controlled delayed-request regression fails before the fix and passes after. Tests cover caller abort, successful delayed identity without replay, and the separate legacy-state timeout. Projection/deep-link/knowledge/overlay tests: 32 passed; TypeScript passes. These tests establish a possible permanent busy path, not the root cause of the production observation. No running instance, frozen candidate or business data was touched. Session-sticker SM decoupling remains unimplemented.
