# 引用与贴纸交互修订

普通贴纸摘要和关闭按钮同排，去掉“写下你的理解”占位文案；Enter 保存、Shift+Enter 换行，中文输入法合成不提交；点击浮窗外和关闭按钮均取消修改。引用数字统一细黑圆圈，位置提升到选文末端右上方。

补齐 Vault 选择框样式，只在旧关联缺少 Vault 身份时显示；顶栏入口放在原生 header.utilities 槽位，同高对齐，不修改 BetterSidebar。

验证：类型检查、构建、编辑键盘/取消、色盘、覆盖层等 17 项定向测试通过。

仅更新客户端产物，保留已安装宿主逻辑、版本兼容声明与其他插件。实例界面由用户验收，不能用合成测试代替。
