# DSH 0.2.0-rc.2 candidate

Uses BetterSidebar 0.24.1 native tab lifetimes. Waits for the real rendered ID; updates and activates using original session scope; retains registered tabs across temporary React unmounts and drops them on lifetime abort. Rejects stale late mounts. Existing sticker, quote, backlink and Vault-binding behavior remains covered by regression tests.

Validated against the actual Launcher 0.2.0-rc.2 distribution in isolated worktrees. Candidate versions use dsh02.1 and have not been published or installed into a real profile/Vault. Unit/integration, type and package checks are recorded in the maintenance report. Native UI layout, scroll, resize, activation, reload and real Obsidian interactions remain unaccepted pending the coordinated browser acceptance run.
