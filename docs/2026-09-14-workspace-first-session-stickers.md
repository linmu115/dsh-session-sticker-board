# 先选工作区再创建独立会话

从选区创建会话贴纸时，点击“新建独立会话”先列出当前 DSH 实例工作区，支持滚动分页和空工作区。选定后显示“在「工作区」中新建会话”，确认才执行创建。可重新选择工作区或返回已有会话选择，取消不会创建会话。

创建请求携带原生 workspaceId。来源回复的固定上游位置、选区与引用在切换选择步骤、失败重试中保留；同一操作重试复用身份。创建成功后维持原有的跨会话引用及贴纸保存流程，不自动发起模型回答。

验证覆盖工作区选择前不创建、选定后正确传递原生 ID、保留固定来源引用、选择已有会话、失败重试及取消。贴纸端完整测试 17 个文件、114 项通过，类型检查通过。
