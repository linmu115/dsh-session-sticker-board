# 来源蓝色标记的右键删除

来源选文旁的蓝色标记现在提供“进入会话”和“删除引用”右键菜单。菜单沿用 DSH 颜色、边框、间距和危险操作样式，支持上下键、Home/End、Escape，以及菜单键或 Shift+F10。

同位置的多个引用共享一个标记和高亮。导航仍按目标会话去重；删除菜单保留每条独立 referenceId，同名目标以引用序号区分。删除其中一条不影响其它引用，也不影响普通红色贴纸或其高亮。

删除通过 `POST /maintenance-knowledge/api/revoke-source-reference` 发送来源 `nativeSessionId` 与选中的 `referenceId`。后端事务负责权威关系撤销和图同步；UI 收到成功 ACK 后才移除该引用，并广播 `dsh-session-references-changed`。失败时保留原标记、选文高亮和菜单，显示错误并允许重试。普通后台刷新遇到临时断线也保留已有标记，导航仍必须经过权威重新验证。

权威撤销之后，UI 尝试通过 Core 现有 `resolveReferenceLink` / `deleteReferenceLink` 清理目标会话本地气泡。导入会话的本地记录缺失或已删除都视为无需清理；本地清理失败不会撤回已成功的权威撤销，而是提示“引用已解除，本地引用气泡暂未同步”。此操作不会创建、打开或删除会话，不会自动发送消息。

2026-09-15 验证：定向 2 个测试文件 / 21 tests、`pnpm typecheck` 通过；完整 `pnpm test` 含 build 通过，19 个文件 / 140 tests。新增覆盖精确撤销、多目标与同目标多引用、失败保留和重试、ACK 前不隐藏/不广播、缺失本地记录、本地清理失败、键盘菜单及临时断线。HTTP 权威接口在这些前端测试中使用 mock；真实 Engine 联调由主任务完成。
